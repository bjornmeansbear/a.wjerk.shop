## Patterns established

**Fluid margin note**
Set `--aside-w: clamp(min, vw, max)` on the element; derive `margin-right: calc(-1 * (var(--aside-w) + gap))` and `top: calc(-1 * (var(--aside-w) * N))` from the same variable so layout stays in sync as viewport widens.

**Multi-section case study**
`article.caseStudyBody` drops `max-width` when it contains `<section>` children. Each `section:has(> .caseStudyText)` gets its own flex layout at 55rem+. Intro text goes in `.caseStudyPreamble` before the first section. Works alongside the existing single-section boombox pattern with no conflicts.

**Prose line discipline**
Every `<p>`, `<td>`, `<li>` as a single long line in HTML. VSCode wraps visually; hard-coded line breaks create mid-sentence splits and make in-editor editing confusing.
